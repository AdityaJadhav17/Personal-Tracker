# US-80, notes

Asked for on 28 September 2026: a notes section in the sidebar for personal
notes, done the way Apple Notes does it.

```
US-80  As someone whose loose thoughts end up in five different apps,
       I want plain notes beside my deadlines,
       so that the grocery list and the thing to ask the landlord live in the
       app I already have open.

Priority: Should
Acceptance criteria:
  AC-80.1  Notes sits in the sidebar after Reflections, and in the phone's
           More sheet. It shows a list of notes beside the note that is open.
  AC-80.2  New note opens an empty note with the cursor in it. The note is
           made by the first thing typed, so one left empty is never kept.
  AC-80.3  A note saves as you type. There is no title field: the first line
           is the title, shown large and bold while writing and bold in the
           list.
  AC-80.4  The list is newest-edited first, grouped Today, Previous 7 Days,
           Previous 30 Days, then by month. Each row shows the title, then the
           time (today), weekday (this week) or date, and the start of the
           rest.
  AC-80.5  Search keeps only the notes containing what you typed, ignoring
           case. No match says so.
  AC-80.6  Delete removes the note with no confirm, and the undo toast brings
           it back.
  AC-80.7  Notes survive a reload, go into the export, and come back on
           import. An import whose notes are not all text is refused. A
           version 5 file still opens, with no notes.
  AC-80.8  On a phone the list fills the screen; opening a note shows it with
           a back button to the list.
```

## Decisions

**Version 6, one new collection.** A note is `{ id, body, createdAt,
updatedAt }`. One hop in `migrate.ts` adds `notes: []`.

**Made on the first letter.** A new note exists only in the view until you
type, so leaving an empty one needs no clean-up, and nothing is deleted
behind your back.

**The first line is the title.** As in Apple Notes. The editor is a
`contenteditable="plaintext-only"` element so `::first-line` can make the
title large without a second field; it holds plain text only and is read
back as text (`innerText`), never as HTML.

**Notes count as data.** An import over notes alone still asks before
replacing, and the backup reminder counts them.

**u is a letter in a note.** Undo's shortcut ignores the editor, as it
ignores every field.

**Not in the calendar file.** Notes have no date, so `.ics` export ignores
them.

**Left out.** Folders, pinning, checklists and formatting, attachments and
locked notes. Each can be its own story.
