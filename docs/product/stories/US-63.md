# US-63, calendar wayfinding

From the second UI audit of 24 September 2026, items 5 and 6.

```
US-63  As someone paging through a term,
       I want a way back to this month and a grid that reads as one piece,
       so that I never get lost two months out.

Priority: Should
Acceptance criteria:
  AC-63.1  A Today button returns to the current month. Previous and Next
           are chevrons that keep their names, "Previous month" and "Next
           month".
  AC-63.2  Days outside the month keep the grid's lines, recessed, so the
           month is one block rather than a ragged shape.
  AC-63.3  A week with nothing due shows no count; the column reads only
           where there is something to read.
  AC-63.4  Today is marked by a filled circle behind its date number, not by
           filling the whole cell.
  AC-63.5  The grid grows to fill the window's height, never shorter than
           it is now.
```

## Decisions

**No neighbouring dates.** Printing the previous month's numbers in the
padding cells would need a second date function for no decision anyone
makes. The recessed cells fix what looked wrong, the ragged edge.
