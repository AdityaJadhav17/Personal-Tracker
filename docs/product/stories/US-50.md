# US-50, a title bar that matches

Phase 4 of the [UI polish plan](../../design/ui-polish-plan.md), from
mobile-native. Built 24 September 2026.

```
US-50  As someone who runs this as an installed app,
       I want its title bar to match the page,
       so that it looks like one window, not a page inside another.

Priority: Could, built
Acceptance criteria:
  AC-50.1  Given each system scheme, a theme-color tag gives the title bar the
           page's background for that scheme.
  AC-50.2  Given I have chosen a theme with the toggle, the title bar takes the
           page's actual background, and still does after a reload.
```

## Decisions

**One tag per scheme,** as mobile-native requires, matched to the colour at the
top of the page: the `--bg` token, `#f7f9f9` and `#0f172a`.

**A chosen theme rewrites both.** mobile-native: when an app switches theme
itself rather than by the system setting, update the tag from JavaScript. The
toggle reads the page's computed background after switching, so the colour is
never written down a third time.

**What needs your eyes.** Whether Chrome paints an installed app's title bar
from these tags cannot be checked from here; the spec proves the tags are right.
