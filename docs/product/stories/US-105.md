# US-105, locked stays locked in every copy

US-105 As the only user of Margin,
I want a locked note to stay locked wherever a copy of it ends up,
and every backup to keep opening the way it was made,
so that locking a note is something I can rely on.

Acceptance criteria:
AC-105.1 A note locked on one device stays locked after sync, even when the
other device, which did not have that lock yet, changed it later; that
later change is not kept.
AC-105.2 An older automatic backup made under another passcode still opens
with that passcode, and holds no readable copy of a note locked since.
AC-105.3 When an older automatic backup cannot be read, backups pause and say
which file, so it can be moved out of the folder.
AC-105.4 Locking a note in another tab updates older backups just as locking
it here does.
AC-105.5 Finishing a repeating item whose next date would fall after the
year 9999 makes no next item.
