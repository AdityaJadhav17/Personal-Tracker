# US-42, accessibility you can check

Step 3 of [the roadmap](../review-and-roadmap.md). Built 24 September 2026.

```
US-42  As someone who sometimes works from the keyboard alone,
       I want every view to meet WCAG 2.2 AA and to skip what I do not need,
       so that nothing in the app needs a mouse or perfect eyesight.

Priority: Must, built
Acceptance criteria:
  AC-42.1  Given any of the six views, in light or dark,
           then an automated WCAG 2.2 AA scan finds nothing.
  AC-42.2  Given a fresh page,
           when I press Tab,
           then the first stop is "Skip to content", which moves focus into
           the main area past the sidebar.
  AC-42.3  Given a deadline on the calendar,
           then I can open its day, open it, change its date and save with
           the keyboard alone.
```

## Decisions

**`@axe-core/playwright`, approved as part of the roadmap.** A development
dependency: it runs inside the Playwright suite and is never bundled, so it
cannot read anyone's deadlines. It replaces nothing; the contrast unit test
stays, because it checks the palette itself rather than one rendered page.

**The scan seeds every group and collection**, so each view is scanned with
content in it rather than as an empty state, and the calendar is scanned with
a day open.

**The skip link is hidden until focused**, then sits over the sidebar's
corner. Focus moves into `<main>`, which takes `tabIndex={-1}` so the link
moves focus, not only the scroll position. It keeps the focus ring the style
sheet promises every element.

## What it took

The scan found nothing on its first run, which proves nothing on its own. So
it was checked by breaking something on purpose. Removing the Done button's
label did not fail it, because the button also carries the text "Done" and
so still has a name; that was the wrong thing to break, not a gap in the
scan. Unlinking the add form's Title label did fail it, with "Form elements
must have labels", and it passed again once restored.

The skip link moved every Tab count by one, and two sidebar specs, one unit
and one Playwright, said so.

The keyboard move needed no new code: US-41's open day already has the row
with its date field. This story's spec proves the path end to end.
