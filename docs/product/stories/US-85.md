# US-85, CI on Node 22

Asked for on 1 October 2026, after every CI run warned that Node 20 is
deprecated on GitHub's runners.

```
US-85  As the person who reads CI,
       I want it on a Node that is still supported,
       so that a warning today does not become a broken build later.

Priority: Should
Acceptance criteria:
  AC-85.1  CI runs the checks on Node 22, the version the laptop runs and the
           updater builds with.
  AC-85.2  The checkout, setup-node and upload-artifact actions are on v7,
           which run on GitHub's Node 24 runtime, so the deprecation warning
           is gone.
```

## Decisions

**22, not 24.** 22 is what this laptop runs (22.18), so CI checks what the
updater builds. 24 can follow when the laptop moves.

**v7 of each action.** The latest major of all three; setup-node v5 and later
cache npm on its own, and `cache: npm` stays so that is explicit.

**Proof is the next CI run.** No test can show a workflow runs on GitHub;
its first run is the check, and a run with no deprecation annotation closes
AC-85.2.
