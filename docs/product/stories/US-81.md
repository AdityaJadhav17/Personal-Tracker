# US-81, pin a note

Asked for on 28 September 2026, after US-80.

```
US-81  As someone with a few notes I open every day,
       I want to pin them to the top of the list,
       so that the grocery list does not sink under whatever I wrote last.

Priority: Could
Acceptance criteria:
  AC-81.1  The open note has a Pin button beside Delete. Pressed, it says
           Unpin note and the note is pinned; pressed again, it is not.
  AC-81.2  Pinned notes sit in their own Pinned group above Today, newest
           edit first, and leave the date groups. A pinned row shows a pin.
  AC-81.3  Pinning does not count as an edit: the note's edited time and its
           place among the other notes stay as they were.
  AC-81.4  A pin survives a reload, an export and an import. An import whose
           pin is not true or false is refused. A version 6 file still
           opens, with nothing pinned.
```

## Decisions

**Version 7, one field.** `pinned: boolean` on every note, false by default.
One hop in `migrate.ts`.

**No undo toast.** Pinning is undone by pressing the same button again.

**Search keeps the groups.** A pinned match still shows under Pinned.
