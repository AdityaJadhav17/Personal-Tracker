# US-88, a daily routine checklist

Asked for on 1 October 2026: a to-do page for "day to day repetitive tasks",
like Notion's checkbox lists. Picked from three sketches: a checklist that
unticks itself every morning.

```
US-88  As someone with the same small things to do most days,
       I want one checklist that starts fresh every morning,
       so that vitamins and the gym get ticked off today without becoming
       deadlines that pile up when I miss one.

Priority: Should
Acceptance criteria:
  AC-88.1  Routine sits in the sidebar after Notes, and in the phone's More
           sheet. It shows today's date and the list.
  AC-88.2  Each task is a line with a checkbox, typed into directly, as in
           Notion. Enter makes a new line below and moves to it; Backspace
           in an empty line removes it and moves up. Typing saves as you go.
  AC-88.3  Ticking marks a task done today. A ticked task stays where it is,
           struck through; ticking again unticks it.
  AC-88.4  At the start of each day every task is unticked again. A missed
           day leaves nothing behind: no overdue, no count of misses.
  AC-88.5  "2 of 4 done today" sits under the list.
  AC-88.6  Delete on a task with words in it removes it, with Undo.
  AC-88.7  Tasks survive a reload, an export and an import; an import whose
           tasks are malformed is refused. A version 8 file still opens, with
           no tasks.
```

## Decisions

**Its own page, not Home.** Home's repeats are deadlines: a missed one goes
overdue and stays until dealt with. A routine missed yesterday should just
be gone. Aditya chose to keep it off Home entirely.

**Done means ticked today.** Each task stores the local day it was last
ticked, `doneOn`, or null. It counts as done when that day is today, so the
reset at midnight needs no job, no timer and no write: yesterday's tick simply
stops matching.

**Version 9.** A new collection, `tasks: { id, title, doneOn, createdAt }[]`,
in the order shown. One hop in `migrate.ts` adds it empty.

**Every task, every day.** No per-task days of the week yet; a task that is
only for Sundays can stay a weekly repeat on Home.

**No history.** Aditya had no preference, so it keeps none: the smallest
thing. `doneOn` holds only the last tick.

**Not in this story.** Reordering by drag, per-task weekdays, history or
streaks, and a strip on Home.
