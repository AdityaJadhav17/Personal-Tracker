# US-96, Margin on the iPhone

Asked for on 13 October 2026, once Tailscale linked the laptop and the iPhone
with Tailnet Lock on. Aditya also asked for a professional name and a proper
logo, and picked Margin.

```
US-96  As someone whose deadlines do not stop when the laptop is closed,
       I want the app on my iPhone's home screen, reached over my own
       private network, opening even with no connection,
       so that the list is in my pocket without being on the internet.

Priority: Must
Acceptance criteria:
  AC-96.1  The server on 4180 also answers the laptop's own Tailscale name
           (machine.tailnet.ts.net), as asked of Tailscale itself. Any other
           name is still refused with a 403. Without Tailscale, only
           localhost and 127.0.0.1 are answered.
  AC-96.2  The app is called Margin: in the sidebar, the page title, the
           installed app and the home screen. Stored data, storage keys and
           the names of exported and backed-up files do not change.
  AC-96.3  Margin has an icon: a home-screen icon for iPhone, icons for the
           installed app on the laptop, and one that survives Android-style
           masking. A web app manifest names it, so Add to Home Screen opens
           it full screen, without Safari's bars.
  AC-96.4  Once opened, the app opens again with no connection to the
           laptop, from what the browser kept. A deploy reaches it on the
           next open that can reach the laptop. Nothing is fetched from
           anywhere but the app's own origin.
  AC-96.5  The README says how: tailscale serve, Add to Home Screen, and
           moving data to the phone with Taildrop until sync exists.
  AC-96.6  (Added 13 October, from audit run 2.) Opening one of the app's
           files as a page, such as the icon, by hand or because another
           site opened it, does not replace the app kept for offline use.
```

## Decisions

**The server asks Tailscale its name.** `tailscale status --json` gives the
laptop's DNS name, so there is nothing to configure and the match stays exact.
It is asked when a request arrives under a name that is not localhost, and
remembered once known; at logon Tailscale may not be up yet. `*.ts.net` as a
pattern would be looser for no gain.

**The service worker is ours, a few dozen lines.** No Workbox: it would be a
dependency for what one file does. Pages are network first, so a deploy shows
on the next open; hashed assets are cache first, since their names change when
their content does. Assets an old page used are deleted once the new page is
cached.

**Display name only.** `personal-tracker/v1`, the backup folder's files and the
export files keep their names. Renaming any of them would orphan data or
backups already made.

**Safe areas were already done** (AC-66.5): the page reaches the screen edges
and the styles keep content off the Dynamic Island and the home indicator.
