# US-103, opens without the laptop

US-103 As someone using Margin on my phone,
I want it to open straight away even when the laptop is asleep,
so that I can read and add things anywhere and let sync catch up later.

Acceptance criteria:
AC-103.1 When the laptop does not answer, the app opens from the copy kept
on the device within about 3 seconds, and a page that arrives later is
still kept for next time.
AC-103.2 A sync request the laptop does not answer ends as "Laptop not
reachable; will sync when it is." within 10 seconds.
