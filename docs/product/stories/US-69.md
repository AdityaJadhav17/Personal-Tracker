# US-69, one page header, one corner scale, spacing that scales

From the final UI polish plan, 25 September 2026
([ui-final-polish-plan.md](../../design/ui-final-polish-plan.md)).

```
US-69  As someone moving between views all day,
       I want every page built the same way,
       so that nothing has to be found twice.

Priority: Could
Acceptance criteria:
  AC-69.1  Goals and Courses put "New goal" and "New course" on the title's
           row, at its far end, in the quiet style the calendar's Today
           uses, not filled.
  AC-69.2  Two corner sizes: 6px for controls, 10px for anything that holds
           content (cards, lists, charts, the add field, the calendar's
           day, messages).
  AC-69.3  The spacing scale is in rem, so it grows with the text size set
           in Windows or the browser.
  AC-69.4  The undo button, calendar items, dates and "more", and "Show the
           numbers" press in like every other button.
```
