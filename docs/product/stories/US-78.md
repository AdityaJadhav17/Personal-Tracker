# US-78, pick the course when adding

Asked for on 27 September 2026, alongside US-77.

```
US-78  As someone adding homework for a class,
       I want to say which course it is for as I add it,
       so that it does not take a second trip into the item to file it.

Priority: Should
Acceptance criteria:
  AC-78.1  Once there are courses, the add form offers Course, starting on
           No course, wherever you add from: Home, a calendar day, and the
           phone's + sheet. With no courses it is not there.
  AC-78.2  An item added with a course is filed under it: its colour, and
           the course filter, from the moment it is added.
```

## Decisions

**No guessing.** The course does not follow Home's course filter or change
the category. Both would be a choice made for you that you would have to
notice and undo.
