# US-98, a goal you can mark achieved

Asked for on 13 October 2026, after Aditya passed his AWS exam and the goal for
it had no way to say so. He chose to mark it himself, and to have achieved
goals gather below the active ones rather than disappear.

```
US-98  As someone who just reached a goal,
       I want to mark it achieved and still see it,
       so that the list shows what I finished, not only what is left.

Priority: Should
Acceptance criteria:
  AC-98.1  Every goal has Mark achieved. An achieved goal moves to an
           Achieved section below the active goals, with a check and the
           day it was achieved in place of the time left. Its name,
           description and progress stay.
  AC-98.2  Mark not achieved puts it back among the active goals. Nothing
           about the goal or its items is lost either way.
  AC-98.3  It survives a reload, an export and an import. Files from
           before this version still import, with every goal not achieved.
  AC-98.4  (From the audit of 13 October, lead 3.) Locking a note or
           changing the passcode deletes the copy kept before the last
           upgrade, so no older copy keeps a locked note readable or under
           the old passcode. Version 10 is the first upgrade since that
           copy existed.
```

## Decisions

**Marked by hand.** Only Aditya knows he passed; done items do not prove it,
and a goal with no items could never complete on its own.

**Deleted, not resealed.** The copy before an upgrade is the stored text as it
was, and the app cannot reseal text it never opened. Once a note is locked or
the passcode changes, losing the undo for a bad migration is the smaller cost;
the automatic backups still hold yesterday.
