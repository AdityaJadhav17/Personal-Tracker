# US-104, sync finishes when the laptop sleeps mid-reply

US-104 As someone using Margin on my phone,
I want sync to give up cleanly when the laptop falls asleep while answering,
so that the Data view tells me the truth instead of "Syncing" forever.

Acceptance criteria:
AC-104.1 A sync reply that stops partway through ends as "Laptop not
reachable; will sync when it is." within 10 seconds of the request.
AC-104.2 A page that arrives after the kept copy has opened is kept, and is
the copy that opens next time.
