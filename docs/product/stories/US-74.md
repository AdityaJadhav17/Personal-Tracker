# US-74, the app is just there

Asked for on 25 September 2026: "I just click the app in my taskbar and it
starts working."

```
US-74  As someone who opens this many times a day,
       I want clicking the taskbar icon to be the whole of it,
       so that I never start, watch or restart a server.

Priority: Must
Acceptance criteria:
  AC-74.1  A server for the deployed app starts at login with no window, and
           stays up: no time limit, running on battery, restarted if it
           stops. The taskbar icon is the Chrome app as it was.
  AC-74.2  It serves only this laptop: it listens on loopback, and answers
           only files inside the deployed folder. A path that climbs out of
           it is refused.
  AC-74.3  A reload after a deploy shows the new version: the page is never
           cached, and the hashed assets always are.
  AC-74.4  It depends on nothing but Node itself, so the updater reinstalling
           packages cannot pull files out from under it.
```

## Decisions

**Always on, not started with the app.** Aditya first asked for the server to
start with the app and stop when it closes. Doing that means the taskbar pin
runs a launcher, which Windows shows as a second icon beside the app, and
deciding the app has closed means watching for its window, which fails when
it is opened twice or restored after a crash. Always on costs about 35 MB
while idle. He chose always on.

**Not Vite's preview server.** It runs out of `node_modules`, which the
updater reinstalls on every deploy; on Windows, replacing files a running
process holds is how a deploy fails.
