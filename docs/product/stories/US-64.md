# US-64, feedback you can act on

From the second UI audit of 24 September 2026, items 7 to 10.

```
US-64  As someone who ticks things off with a mouse,
       I want undo I can click, warnings that fit what they warn about, and
       a Delete that looks like one,
       so that slips are cheap and nothing shouts.

Priority: Should
Acceptance criteria:
  AC-64.1  Marking something done shows a message with an Undo button that
           does what the u key does. The message floats at the foot of the
           window and fades after a few seconds; u still works after.
  AC-64.2  Overdue is a red heading over plain rows: no tinted box.
  AC-64.3  When a backup is due, the Data view says so in the danger colour
           and Export is the filled, primary button. When one is not due,
           Export looks like every other tool.
  AC-64.4  In an open row, Delete is red text, set apart from Save at the
           far end. Its "Yes, delete" is a red button.
```
