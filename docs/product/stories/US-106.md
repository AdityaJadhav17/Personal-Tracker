# US-106, locked stays locked, whatever the timing

US-106 As the only user of Margin,
I want a locked note to stay locked even when something happens on this
device in the same moment the lock arrives,
so that no edit or Undo here can make it readable again.

Acceptance criteria:
AC-106.1 A note that is locked is never saved readable by an edit that was
typed before the lock arrived; that edit is not kept.
AC-106.2 Once a passcode first reaches this device, set here, synced or
imported, Undo can no longer bring back what it could before.
