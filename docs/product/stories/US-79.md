# US-79, copy an item by dragging with Ctrl

Asked for on 27 September 2026: "a copy function in the calendar", by
dragging. Aditya chose Ctrl over a question on every drop.

```
US-79  As someone whose weekly work repeats in odd patterns,
       I want to copy an item to another day by dragging it,
       so that a second lab report or reading quiz is one gesture.

Priority: Could
Acceptance criteria:
  AC-79.1  Dragging an item to a day moves it, as before. Holding Ctrl as it
           drops copies it instead, and the pointer shows a copy while Ctrl
           is held. A line says what was copied and where.
  AC-79.2  The copy keeps the title, time of day, category, priority,
           course, goal and note. It does not repeat and has no steps, and
           the original is untouched.
  AC-79.3  Undo removes the copy.
  AC-79.4  Hovering an item that can be dragged says how to move and copy
           it.
```

## Decisions

**Ctrl, not a question.** Asking "move or copy?" on every drop would add a
click to every move, and moves are the common case. Ctrl while dropping is
how Windows Explorer copies.

**A copy never repeats.** Copying a weekly item and keeping the repeat would
start a second series of the same thing.
