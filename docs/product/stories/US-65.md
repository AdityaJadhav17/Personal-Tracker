# US-65, details

From the second UI audit of 24 September 2026, items 11 to 13.

```
US-65  As someone reading goals and trends,
       I want dates that say how long is left and one copy of each number,
       so that each view answers its question at a glance.

Priority: Could
Acceptance criteria:
  AC-65.1  A goal shows its target as "Oct 10 · 16 days left", "Today",
           "Tomorrow" or "Passed", without a time of day.
  AC-65.2  Trends' table of numbers sits in a disclosure, "Show the numbers",
           closed to start. It is still a real table once open.
  AC-65.3  The theme button sits at the foot of the sidebar, apart from the
           views.
```

## Decisions

**No System choice for the theme.** A third state for a setting that is
pressed a few times a year is more than it earns. The system still decides
until the button is pressed.
