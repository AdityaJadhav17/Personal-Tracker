# US-62, one visual system

From the second UI audit of 24 September 2026, items 1 to 4 and 14.

```
US-62  As someone who checks this many times a day,
       I want colour, buttons and headings to follow one set of rules,
       so that the page is calm and colour points only at what I can press.

Priority: Should
Acceptance criteria:
  AC-62.1  The sidebar follows the theme: light in light mode, dark in dark.
           Its title and links use tokens, not fixed white, and still reach
           4.5:1 in both.
  AC-62.2  Body text is neutral, not teal. The accent is kept for things you
           can press and for "you are here".
  AC-62.3  Buttons come in two heights: regular (2.25rem) for actions in the
           page and small (1.75rem) for actions inside a row. Every button in
           a view uses one of the two.
  AC-62.4  Section headings share one style: sentence case, never uppercase
           by CSS. Only the calendar's weekday names stay in capitals.
  AC-62.5  Home has no reserved gap between the add field and the list: the
           status line takes no space while it is empty.
```

## Decisions

**The sidebar leaves the reference screenshots.** The reference had a dark
sidebar in both themes. In light mode it was the heaviest thing on screen, so
it pulled the eye from the deadlines. It is one token pair to put back.

**Two sizes, not three.** A large size had no caller.
