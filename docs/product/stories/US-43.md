# US-43, a term from a calendar file

Step 5 of [the roadmap](../review-and-roadmap.md). Built 24 September 2026.
Research problem 1: getting the term in costs so much that people never
finish. This quarter went in because three PDFs were read by hand.

```
US-43  As someone whose courses already publish their deadlines,
       I want to add them from a calendar file instead of typing them,
       so that setting up a term is a download and a confirm.

Priority: Should, built
Acceptance criteria:
  AC-43.1  Given an event in UTC, it becomes a deadline at that moment.
  AC-43.2  Given an all day event, it is due at 11:59pm; a time with a named
           zone is read as local wall clock; a to-do uses its due date.
  AC-43.3  Folded lines, escaped text and bare LF line endings all read.
  AC-43.4  Events already past, and cancelled ones, are left out and counted.
  AC-43.5  An event with no title or no readable date is skipped, not guessed.
  AC-43.6  A weekly or monthly rule becomes a repeat; others import once.
  AC-43.7  A file that is not a calendar, or is too large, is refused and
           says why; markup in a title stays text.
  AC-43.8  A deadline already held, same title and same moment, is not added
           twice.
  AC-43.9  Choosing a file shows what would be added and what was left out,
           and saves nothing.
  AC-43.10 Add saves them, under a course if one was picked; Cancel does not.
```

## Decisions

**You download, the app reads.** Canvas publishes a calendar feed and some
course sites have a "Download iCal File" button. Fetching those would be the
network request the security posture forbids, so the file is chosen by hand
like the JSON import.

**Hostile input, like the JSON import.** Capped at the same 5 MB, read as text,
nothing evaluated, only four properties looked at. React renders titles as
text.

**Named timezones are read as local.** Real conversion needs timezone tables,
a dependency, for files that in practice come from the zone this app runs in.
A feed from elsewhere would be off by the difference; UTC times, which is what
Canvas writes, are exact.

**The label avoids the word "Import".** Playwright matches labels by
substring, and "Import calendar" would have collided with the JSON Import in
every spec that uses it.

## What it took

`user-event` honours `accept=".ics"` and silently dropped the wrong-file test's
JSON, so that test uploads without the filter, as a real "All files" picker
would.

The longer label beside a file input overflowed a 320px phone, which the
US-23 narrow specs caught. The label and input now wrap.
