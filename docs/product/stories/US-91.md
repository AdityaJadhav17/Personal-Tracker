# US-91, diagrams and a README that matches the app

Asked for on 4 October 2026, after Archify was installed and used to draw the
repository.

```
US-91  As the owner of a repository other people may open,
       I want its README and pictures to show the app as it is now,
       and diagrams of how it works,
       so that the first page tells the truth.

Priority: Could
Acceptance criteria:
  AC-91.1  docs/diagrams holds the architecture, workflow and personal-data
           diagrams: a PNG each, the interactive HTML, and the JSON source.
  AC-91.2  The README links them, and its screenshots show Home, Calendar,
           Notes and Routine as they are, with made-up data.
  AC-91.3  The README's description matches the app: nine views, Work, Undo
           in place of confirmations, holidays, copying by Ctrl-drag, notes,
           locked notes and the routine.
  AC-91.4  Archify's working folder, .archify, is ignored; its generated files
           are left out of Prettier; ESLint skips the local .claude folder
           where the skill is installed.
```

## Decisions

**Screenshots from made-up data on the dev server.** Never the real data on
port 4180. The page clock was set to Thursday 8 October 2026, so the month
shows holidays and a full week.

**Diagrams pinned to one commit.** Archify checked every cited line at
`47b1fd7`. When the code changes, redraw from the JSON beside each PNG.

**The skill stays local.** It is installed in `.claude/skills/archify`, which is
gitignored, from the project's release zip rather than through `npx skills`,
and run with its update check off.
