# US-76, a work category

Asked for on 27 September 2026: "a work category as well, apart from
personal and education".

```
US-76  As someone with a job alongside classes,
       I want work deadlines to be their own kind of thing,
       so that I can see just them, or everything but them.

Priority: Should
Acceptance criteria:
  AC-76.1  Work is a category beside Academic and Personal: offered when
           adding, and as a Work chip in Home's filter.
  AC-76.2  A backup with work items imports; an unknown category is still
           refused.
  AC-76.3  Nothing already stored changes, so the database stays at
           version 5.
```

## Decisions

**Academic keeps its name.** Aditya called it education; the app has always
said Academic, and renaming it was not asked for.

**New items still start as Academic,** as do pasted lists and calendar files.
