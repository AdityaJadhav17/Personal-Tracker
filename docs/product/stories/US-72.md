# US-72, Windows contrast themes

From the final UI polish plan, 25 September 2026
([ui-final-polish-plan.md](../../design/ui-final-polish-plan.md)).

```
US-72  As someone who might turn on a Windows contrast theme,
       I want every marker the app draws to survive it,
       so that the theme makes the app easier to read, not emptier.

Priority: Could
Acceptance criteria:
  AC-72.1  With forced colours on, whatever says "this one" still shows:
           the current tab, the chosen filter, the chosen mood and today's
           date, each in the system's highlight colours.
  AC-72.2  Course dots and the goal progress bar stay visible, in the
           system's text and highlight colours.
  AC-72.3  The open calendar day and a drop target keep their ring, drawn
           as an outline, since forced colours remove shadows.
  AC-72.4  The undo message, the phone sheets and the calendar's day keep
           an edge, so they do not melt into the page behind them.
```

## Decisions

**System colours, not ours.** In a forced colours theme the person chose
their colours, so the markers use Highlight, HighlightText and CanvasText
instead of keeping the course hues. The course name beside each dot still
says which course it is.
